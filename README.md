## 🎬 网页视频助手

[👉 点击安装](https://raw.githubusercontent.com/medicandong/sousou/refs/heads/main/videos.user.js)

一堆bug。原本打算在 Edge 浏览器中使用，解决网页视频无法自动横屏的问题，目标是实现类似华为浏览器的视频播放助手。尝试多次仍未成功，有大佬愿意修复的话感激不尽！

功能设想：基于 华为浏览器网页视频助手 设计。好用，但是别的浏览器木有这个功能。

1. 自动横屏/竖屏播放。edge浏览器网页视频播放时，需要开启手机自动旋转功能，然后再横屏，才能使用全屏播放，想解决这个问题
2. 倍速调整。倍速为0.5 1 1.5 1.75 2.0 2.25 2.5 3.0 4.0
3. 适配YouTube。
4. 画面尺寸。填充 拉伸 适应 原始等几种类型。主要是使用YouTube的时候，有的视频不能全屏，四周留白很多，看着别扭
5. UI设计。类似华为浏览器的网页助手一样，美观便捷

## 📖 小说阅读助手

[👉 点击安装](https://raw.githubusercontent.com/medicandong/sousou/refs/heads/main/reader.user.js)

施工中，功能尚未完善，仍在调试中。

功能设想：基于 VIA浏览器阅读模式 设计。之前有一个，设置项太多了，还有收费的，不想吐槽。

1. 阅读模式。任意网页均可进入阅读模式。小说网页可去除无效元素，只保留正文和标题界面，可正常点击下一章/下一页等元素。
2. 基础设置。首行缩进，段落间距/文本间距可自定义调整
3. UI美化。右下角出现一个【阅】字，点击展开选项卡，阅读模式、基础设置均在里面。进入阅读模式后，【阅】字变为【X】，点击退出
   
   小声逼逼，其实华为的那个阅读模式更好用，不过好像不好适配，VIA的看着比较简单。有大佬感兴趣的可以搞搞。
   
   正常阅读小说用开源阅读就ok了，网页阅读主要嘛，咳，看一些你懂的短片小说用的，这种网站一般广告贼多，一不小心就跳转出去了。
